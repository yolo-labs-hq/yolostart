yolostart is a native command-line tool for bringing a local project into a YOLO Studio workspace. It reads your project on your machine, opens browser sign-in, and asks you to approve what comes along before anything uploads — with no Node or npm installation required. It runs on macOS and Linux, on Intel and ARM.

curl -fsSL https://yolostart.sh | sh

Select the command to copy it. Run it from your project folder.

Read the script first

Import approval and workspace creation are live: yolostart scans your project, you approve exactly what comes along in the browser, and it lands in a running workspace. To sign in and inspect the scan manifest without uploading anything, add -s -- --dry-run after sh.

Already have Node? Same tool, same verified binary:

npx yolostart

A small wrapper that downloads this same native binary and checks it, so both routes run identical code. The shell installer needs no Node at all.
