yolostart is a native command-line tool for bringing a local project into a YOLO Studio workspace. It reads your project on your machine and opens browser sign-in, with no Node or npm installation required. It runs on macOS and Linux, on Intel and ARM.

curl -fsSL https://yolostart.sh | sh

Select the command to copy it. Run it from your project folder.

Read the script first
